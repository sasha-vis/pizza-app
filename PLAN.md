## 🍕 Проект 1 — Доставка еды (food delivery)

**Репозиторий:** `pizza-app`

### Сейчас (факт из репо)

- React **17**, **CRA** (react-scripts 4.0.3) — самый старый из всех.
- react-router-dom **v5**, react-slick (карусель).
- **Чистый фронтенд**: нет бэка, нет БД, нет TypeScript, нет менеджера состояния.
- Деплой на gh-pages.
- По сути — это самый большой «переписать почти с нуля», но домен простой → отлично для обучения.

### Целевое состояние

Современный SSG/ISR-каталог товаров с корзиной и оформлением заказа без авторизации: пользователь набирает корзину → вводит адрес и телефон → заявка падает в БД. Менеджер видит заявки в админке Supabase.

### Рекомендованный стек

| Слой         | Технология                                                    | Зачем                                                                                                     |
| ------------ | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Фреймворк    | **Next.js (App Router) + TypeScript**                         | SSG/ISR для каталога (данные меняются редко) → быстрый первый рендер + SEO. Это твой Next-витрина-проект. |
| Server-state | **TanStack Query**                                            | Загрузка/кэш меню из Supabase.                                                                            |
| Client-state | **Zustand**                                                   | Корзина (количество, итог).                                                                               |
| Бэк + БД     | **Supabase (Postgres)**                                       | API, БД, хранилище картинок, **готовая админка**. Свой бэк не нужен.                                      |
| Стили        | Tailwind                                                      | —                                                                                                         |
| Деплой       | **Vercel** (фронт) + Supabase (БД/API)                        | Чистый, бесплатный, идеальная связка с Next.                                                              |
| ⚠️ НЕ ставим | Vite (Next свой сборщик), RTK, отдельный Express, авторизацию | Лишнее для этого домена.                                                                                  |

### Новые фичи

- Каталог с категориями, карточка товара, поиск/фильтр.
- Корзина (Zustand) + страница checkout (адрес, телефон, валидация).
- Запись заказа в Supabase, статус «заявка принята».
- (Опц.) Storybook на карточки/кнопки — если захочешь показать навык компонентного подхода.
- (Опц.) PWA — мобильный заказ.

### Деплой

Vercel + Supabase. **VPS не нужен. Денег не нужно** (бесплатные тарифы).
